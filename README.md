# Kafo frontend prototype

Responsive mobile-first prototype using HTML, CSS and vanilla JavaScript only.

## Run in VS Code
1. Extract the ZIP and open `kafo-frontend` in VS Code.
2. Install the **Live Server** extension if needed.
3. Right-click `index.html` and select **Open with Live Server**.
4. Visit the localhost URL shown in your browser.

Use localhost/HTTPS rather than double-clicking the HTML file for service-worker/PWA functionality.

## Included
- Responsive dashboard and mobile navigation
- My Groups search/filter and public Discover category filters
- Three-step group creation with live preview
- Group details: overview, contributions, expenses and updates
- Sample contribution, expense and update forms
- Editable demo profile, preference toggles and reset action
- LocalStorage persistence, manifest, SVG icon and service worker

## Important
This is a frontend demo only. All data is sample data stored in this browser. Wave/QMoney choices are labels only: there is no payment processing, verification, real account, backend or secure permission enforcement. Do not use it to collect real money or sensitive personal information. Production needs authentication, server-side permissions, a database, audit history, backups, payment integrations, legal review and security testing.
